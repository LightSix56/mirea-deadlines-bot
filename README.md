# Telegram-бот дедлайнов СДО РТУ МИРЭА (online-edu.mirea.ru)

Умный бот для непрерывного мониторинга СДО РТУ МИРЭА: отслеживает открытие тестов, перенос и продление дедлайнов преподавателями, появление новых работ и напоминает о горящих сроках.

---

## 🚀 Возможности

1. **🔓 Момент открытия тестов и заданий:**
   * Как только наступает дата открытия теста/практики — бот моментально присылает сообщение `🔓 Открыт доступ к тесту! [Начать выполнение]`.
2. **🔄 Отслеживание переноса дедлайнов:**
   * Если преподаватель сдвинул дедлайн вперед (продлил) или назад — бот присылает алерт с указанием старой и новой даты (`🗓 Было: ... ⏰ Стало: ... (Продлен на N дн.)`).
   * Напоминания автоматически пересчитываются под новый срок сдачи.
3. **🆕 Новые задания:**
   * При появлении в СДО нового предмета или работы бот присылает уведомление с прямой ссылкой.
4. **⚠️ Горящие дедлайны:**
   * Автоматические напоминания за **24 часа** и за **3 часа** до сдачи.
5. **📱 Команды:**
   * `/deadlines` — интерактивный список всех актуальных дедлайнов и открытий.
   * `/check` — принудительный опрос СДО прямо сейчас.

---

## 🛠 Запуск

```cmd
cd /d D:\mirea_deadlines_bot
```
